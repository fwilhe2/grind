# A grind project

Set up by `grind init --template text`. `notes.grind` is a text document written by hand: one
block a line, so a change is a line of diff. This file is yours — rewrite it to say what your
project is, and keep or drop the notes below.

## Working on it

| | VS Code | Command line |
|---|---|---|
| Check it for problems | the *grind: lint* task | `grind lint notes.grind` |
| Read it as text | | `grind text view notes.grind` |
| Hand it to somebody | | `grind convert notes.grind notes.odt` |
